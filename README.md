## 2. Public vs. Private IPs & NAT

* **Private IP:** Internal address used inside a local network (e.g., `192.168.x.x` or `10.x.x.x`).
* **Public IP:** External address assigned by your ISP to your router; visible to the internet.
* **NAT:** Translates multiple private IPs into one single public IP so your entire home shares one internet connection.

## 3. Static vs. Dynamic IPs

* **Dynamic IP:** Automatically assigned by the router (via DHCP); changes over time. Default for home devices.
* **Static IP:** Manually configured and permanent. Used for servers and lab targets so their address never changes.

## 1. Data Encapsulation & Decapsulation

Data flows down the OSI model on the sending device (**Encapsulation**) and moves up on the receiving device (**Decapsulation**).
<img width="959" height="539" alt="encapslate decapsalet " src="https://github.com/user-attachments/assets/58b7278d-e3b0-4021-92aa-b8cde2ebae42" />


### The Encapsulation Process
1. **Application / Presentation / Session (Layers 7–5):** Data is generated by an application and formatted into raw **Data**.
2. **Transport Layer (Layer 4):** Adds a TCP/UDP header (with source/destination ports) $\rightarrow$ **Segment**.
3. **Network Layer (Layer 3):** Adds an IP header (with source/destination IP addresses) $\rightarrow$ **Packet**.
4. **Data Link Layer (Layer 2):** Adds an Ethernet header (with source/destination MAC addresses) and a trailer $\rightarrow$ **Frame**.
5. **Physical Layer (Layer 1):** Converts the frame into raw binary signals (light, electricity, or RF) $\rightarrow$ **Bits**.

---

## 2. OSI Model 7-Layer Quick Reference

| Layer # & Name | Protocol Data Unit (PDU) | Core Addressing / Header Data | Associated Devices |
| :--- | :--- | :--- | :--- |
| **7. Application** | Data | HTTP, HTTPS, DNS, DHCP, SSH | Software Applications |
| **6. Presentation**| Data | Encryption (TLS/SSL), Formats (JPEG, JSON) | OS Kernel / Software |
| **5. Session**     | Data | Session IDs, RPC | OS Kernel / Software |
| **4. Transport**   | Segment / Datagram | **Port Numbers** (TCP / UDP) | Firewalls, Load Balancers |
| **3. Network**     | Packet | **IP Addresses** (IPv4 / IPv6) | **Routers**, Layer 3 Switches |
| **2. Data Link**   | Frame | **MAC Addresses** | **Switches**, Bridges, NICs |
| **1. Physical**    | Bits | Electrical Voltages / Light Pulses | **Hubs**, Repeaters, Cables |

---

## 3. High-Priority Protocols & Ports

- **DNS (Port 53):** Translates domain names to IP addresses.
- **DHCP (Ports 67 & 68):** Automatically assigns IP addresses to devices.
- **SSH (Port 22):** Secure, encrypted remote command-line administration.
- **TELNET (Port 23):** Unencrypted, legacy remote command-line access.
- **HTTP (Port 80):** Unencrypted web browsing.
- **HTTPS (Port 443):** Encrypted, secure web browsing.
- **FTP (Ports 20 & 21):** File transfers.

# NAT Security Concepts

## 1. Cisco NAT Address Mapping
| Term | Context | Function |
| :--- | :--- | :--- |
| **Inside Local** | Internal Network | Private IP assigned to internal host |
| **Inside Global** | Public Internet | Public IP representing internal host to outside world |
| **Outside Local** | Internal Network | Target destination address as seen locally |
| **Outside Global** | Public Internet | Public IP assigned to external target server |

## 2. Hardware Mechanics (Layer 2 vs Layer 1)
- **Layer 2 (Switching):** Uses Destination MAC addresses and CAM tables for frame forwarding.
- **Layer 1 (Hubs):** Legacy devices that broadcast frames to all ports, creating single collision domains.

## 3. Communication Models
- **Broadcast:** 1-to-All delivery. Used in ARP and DHCP.
- **Multicast:** 1-to-Group delivery. Used in specialized media streaming and routing updates.
